# Project: Startup Autónoma

## Overview
Sistema jerárquico de agentes (CEO -> Chiefs -> Workers) para la automatización total de una startup de software y negocios.

## Current Status
- **Fase A:** 100% Completada. Departamento comercial operativo.
- **Fase B:** Iniciada. Infraestructura de UI (Next.js 15 + shadcn) en construcción.

## Key Decisions
- **Orquestación:** LangGraph.js en el backend.
- **IA Heavy:** Python (ai-engine) conectado vía gRPC.
- **UI:** React 19, Tailwind CSS y shadcn/ui.
- **Memoria:** Sistema PARA integrado en la documentación para persistencia organizacional.

## Next Steps
1. Implementar streaming real de pensamientos (SSE) en el Dashboard.
2. Configurar HITL (Human-in-the-loop) para aprobación de misiones comerciales.
3. Conectar el Lead Gen Worker con APIs reales.
